# TFM---Gobernanza-calidad-y-modelado-dimensional-de-datos-abiertos-en-el-sector-p-blico
Sistema de observabilidad y modelado dimensional sobre datos abiertos de ReNaBaP y FISU en Argentina. Mediante una arquitectura Medallón en Python y Power BI, el proyecto audita la calidad del dato, rescata presupuestos huérfanos y analiza la evolución del financiamiento socio-urbano.
