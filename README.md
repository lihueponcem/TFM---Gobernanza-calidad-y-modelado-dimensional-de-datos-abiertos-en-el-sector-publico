# TFM: Gobernanza, Calidad y Modelado Dimensional de Datos Abiertos (ReNaBaP y FISU)

Este repositorio contiene el código de ingeniería de datos y la arquitectura analítica desarrollada para el Trabajo de Fin de Máster (TFM) del Máster en Data Analytics de la Universidad Internacional de Valencia (VIU).

## 🛠️ Estructura del Código
* `Dataset TFM - ReNaBaP.ipynb`: Pipeline de extracción, limpieza en Capa Plata y generación de la dimensión maestra en Capa Oro para el padrón de barrios.
* `Dataset TFM - FISU.ipynb`: Normalización (desanidado N:M), prorrateo presupuestario y construcción de la tabla de hechos en Capa Oro para proyectos de infraestructura.

## 📊 Fuentes de Datos Originales
Los datos abiertos originales utilizados en este proyecto provienen del Portal Oficial de Datos Abiertos de la República Argentina:
* [Registro Nacional de Barrios Populares (ReNaBaP)](https://datos.gob.ar)
* [Fondo de Integración Socio Urbana (FISU)](https://datos.gob.ar)
